# Software | Leitor de Temperatura

Documentação e código da parte lógica do projeto **T02-Ps-2026.2**, desenvolvido pelo Time 02.

## Objetivo

Esta pasta reúne o software responsável por trabalhar com as informações do leitor de temperatura e integrar-se ao hardware descrito em [`../hardware/`](../hardware/). A implementação deve deixar claros o formato dos dados recebidos e o comportamento esperado em caso de leitura inválida ou falha de comunicação.

## Estrutura

A organização dos arquivos deve acompanhar a tecnologia escolhida pelo time. Quando o código for adicionado, documente aqui os diretórios principais e a função de cada um, mantendo os passos de uso próximos da implementação.

## Como executar

Os comandos de instalação, configuração e execução dependem da stack e do ambiente definidos para o projeto. Inclua-os nesta seção assim que estiverem estabelecidos, com os pré-requisitos necessários para reproduzir a execução.

## Como validar

Documente os testes e as verificações disponíveis, incluindo como executá-los e o que cada um cobre. Se houver integração com o sensor ou com uma placa, diferencie a validação em hardware real da execução sem o dispositivo.

## Integração com o hardware

Mantenha o código e a documentação consistentes com as conexões e a interface registradas em [`../hardware/`](../hardware/). Registre também as unidades e o formato das leituras para que a comunicação entre as partes seja inequívoca.

> **Estado da documentação:** comandos, arquitetura e detalhes de integração devem ser atualizados quando a implementação e o ambiente forem definidos pelo time.

# Hardware | Leitor de Temperatura

Documentação da parte física do projeto **T02-Ps-2026.2**, desenvolvido pelo Time 02.

## Objetivo

Reunir as informações necessárias para entender, montar e reproduzir o hardware do leitor de temperatura. Esta documentação acompanha a implementação: componentes, conexões e procedimentos devem refletir o circuito efetivamente utilizado.

## O que documentar

- **Componentes:** sensores, placas, módulos e demais materiais, com modelos e quantidades.
- **Circuito:** esquemático e identificação das conexões entre os componentes.
- **Montagem:** orientações de ligação, alimentação e cuidados relevantes.
- **Validação:** procedimento usado para verificar as leituras e registrar os resultados.
- **Referências:** datasheets e documentação técnica dos componentes escolhidos.

## Organização sugerida

À medida que o hardware for definido, mantenha nesta pasta os arquivos relacionados ao circuito — por exemplo, esquemáticos, diagramas e lista de materiais — e atualize este README para apontar para eles.

## Integração com o software

Registre aqui qualquer detalhe de hardware que afete a integração, como a interface de comunicação e a identificação dos pinos. As informações devem corresponder à montagem documentada e ao código em [`../software/`](../software/).

> **Estado da documentação:** os detalhes do circuito devem ser preenchidos conforme os componentes e a montagem forem definidos pelo time.
